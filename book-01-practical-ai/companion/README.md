第一冊 companion：用 AI 解決實際問題

用途

本資料包供第一冊讀者逐章練習，並為第 11 章「一週工作助理」提供共用資料。所有資料均為測試或去識別化示例，不代表真實公司資料。

目錄

- sample-data/：共用練習資料
- prompt-templates/：可重用 Prompt 模板
- checklists/：人工核對和安全檢查表
- workflow-cards/：工作流程卡
- capstone/：第 11 章綜合專案規格、輸出格式和 replay report

使用規則

1. 先閱讀每個檔案的用途和限制。
2. 不要把示例中的日期、人物或狀態當成真實資料。
3. AI 產出只能先放在 outputs/ 或副本中。
4. 未經人工批准，不得寄信、建立正式任務、修改正式表格或作出對外承諾。
5. 每個結果都要保留來源檔案和模板版本。

建議路線

- 初次閱讀：chapter 01 → 02 → 03 → 04 → 07 → 11
- 文件和資料路線：chapter 01 → 02 → 05 → 06 → 09 → 11
- 工作流程路線：chapter 01 → 04 → 07 → 08 → 10 → 11
- 進階路線：完成第 11 章後閱讀第 12 章，再進入第二冊。

不包含的功能

本資料包不會自動呼叫模型、不會寄出電郵、不會連接公司系統，也不會替讀者完成人工批准。
