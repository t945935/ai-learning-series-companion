# 一週工作助理流程卡 v1.0

## 流程

```text
收集來源
  → 去除不必要敏感資料
  → AI 整理與分類
  → 來源和欄位檢查
  → 人工批准
  → 產出摘要、行動清單和電郵草稿
  → 如要執行外部操作，再由有權限的人手動執行
  → 讀回實際狀態
```

## 停止條件

- 收件人不明：停止。
- 日期或承諾未確認：停止，不自行補充。
- 發現個人資料或秘密：停止，先去識別化。
- AI 輸出沒有來源：停止，回到原文核對。
- 需要退款、付款、刪除、寄信或修改正式資料：停止，等待人工批准。
- 執行後沒有可讀回的系統狀態：不得標示為 executed。

## 證據

至少保留：來源檔案、模板版本、AI 草稿、人工核對表、批准人、批准時間和實際執行後的狀態。
