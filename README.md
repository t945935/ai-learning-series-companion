## 下載

### 下載整個資料庫

```bash
git clone https://github.com/t945935/ai-learning-series-companion.git
```

也可以在 GitHub 頁面按 Code → Download ZIP。

### 只下載單一檔案

在 GitHub 開啟檔案後，按 Raw；例如第一冊第 5 章使用的測試資料：

- `book-01-practical-ai/companion/sample-data/project-policy.md`
- `book-01-practical-ai/companion/sample-data/meeting-notes.md`

## 使用方式

1. 先閱讀對應書籍章節，再下載該章列出的資料。
2. 將來源檔案複製到自己的練習資料夾，不要直接修改來源檔案。
3. 使用去識別化的測試資料進行練習；不要放入真實客戶資料、密碼、API 金鑰或未公開合約。
4. AI 產出先保存為草稿，完成來源、期限、權限和安全核對後再採用。
5. 未經人工批准，不要寄信、建立正式任務、修改正式資料或作出對外承諾。
